# Dépôt Creatif

Boîte à outils partagée, sans application.
- Ne pas modifier à la main `.claude/skills/`, `inspirations/`, `licenses/` : passer par `scripts/sources.txt` puis `bash scripts/sync.sh`.
- Toute modification de la sélection doit être reportée dans `README.md`.
- Diffusion : installé dans `~/.claude/` à chaque démarrage des sessions cloud AntoCala ; copies locales via `bash scripts/maj-outils.sh` dans `Modele-Projet`.
- Ne jamais y mettre de données personnelles.
